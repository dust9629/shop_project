## 기능 명세서 ( 노션 )

<h3>사용자 관련 기능</h3>





3. 매거진 관리
    - 관리자는 매거진을 새로 작성, 수정, 삭제할 수 있는 전체적인 관리 권한을 가진다.
    - 매거진 관리 기능을 통해 관리자는 공개 전 내용을 최종 검토하고, 필요한 경우 수정할 수 있다.
    - 관리자는 또한 사용자의 댓글을 관리할 수 있으며, 부적절한 댓글을 삭제할 수 있다.
